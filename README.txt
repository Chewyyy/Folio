Folio GitHub Pages Files

Upload these files to the same folder in your GitHub repository:

- index.html
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- manifest.webmanifest

For GitHub Pages, they can go in the repository root, or in the /docs folder if your Pages setting uses /docs.

After pushing them, open your GitHub Pages URL in Safari, then use Share > Add to Home Screen.
If you already saved Folio to the Home Screen, delete the old Home Screen icon and add it again.
